# Ручные тесты работоспособности системы

Этот документ содержит пошаговые тесты для проверки всех компонентов системы Task Board.

## 📋 Перед началом тестирования

Убедитесь, что все компоненты запущены:
- ✅ PostgreSQL (Docker): `docker compose ps` - должен показать `trello-db` в статусе `Up`
- ✅ Backend (локально): `curl http://localhost:3223/health` - должен вернуть `{"status":"ok"}`
- ✅ Frontend (локально): браузер на `http://localhost:3000` - должна открыться страница

---

## 1️⃣ Тест PostgreSQL (База данных)

### 1.1. Проверка запуска контейнера
```bash
docker compose ps postgres
```
**Ожидаемый результат:** Статус `Up (healthy)`

### 1.2. Проверка подключения к БД
```bash
docker compose exec postgres psql -U trello -d trello -c "SELECT version();"
```
**Ожидаемый результат:** Версия PostgreSQL 16.x

### 1.3. Проверка наличия таблиц
```bash
docker compose exec postgres psql -U trello -d trello -c "\dt"
```
**Ожидаемый результат:** Список из 10 таблиц:
- Board
- Card
- CardAssignee
- Checklist
- ChecklistItem
- Comment
- Label
- Link
- List
- User

### 1.4. Проверка данных в таблицах
```bash
# Проверка пользователей
docker compose exec postgres psql -U trello -d trello -c "SELECT COUNT(*) FROM \"User\";"

# Проверка досок
docker compose exec postgres psql -U trello -d trello -c "SELECT COUNT(*) FROM \"Board\";"

# Проверка карточек
docker compose exec postgres psql -U trello -d trello -c "SELECT COUNT(*) FROM \"Card\";"
```
**Ожидаемый результат:** Числа (могут быть 0 если база пустая)

## 2️⃣ Тест Backend API

### 2.1. Health Check
```bash
curl http://localhost:3223/health
```
**Ожидаемый результат:** `{"status":"ok"}`

### 2.2. GET /api/boards - Получение списка досок
```bash
curl http://localhost:3223/api/boards
```
**Ожидаемый результат:** JSON массив `[]` или список досок

### 2.3. POST /api/boards - Создание доски
```bash
curl -X POST http://localhost:3223/api/boards \
  -H "Content-Type: application/json" \
  -d '{"title":"Тестовая доска","description":"Описание","color":"#1E3A8A"}'
```
**Ожидаемый результат:** JSON объект с созданной доской, включая `id`

### 2.4. GET /api/users - Получение пользователей
```bash
curl http://localhost:3223/api/users
```
**Ожидаемый результат:** JSON массив `[]` или список пользователей

### 2.5. POST /api/users - Создание пользователя
```bash
curl -X POST http://localhost:3223/api/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Тестовый Пользователь","email":"test@example.com","color":"#3B82F6"}'
```
**Ожидаемый результат:** JSON объект с созданным пользователем

### 2.6. Проверка логов Backend
В терминале где запущен `npm run dev` должны быть видны:
- `Server running on http://localhost:3223`
- Нет ошибок подключения к БД
- Логи запросов (если настроены)

## 3️⃣ Тест Frontend

### 3.1. Доступность интерфейса
Откройте в браузере: `http://localhost:3000`

**Ожидаемый результат:**
- ✅ Страница загружается без ошибок
- ✅ Видна кнопка "Пользователи" в верхнем правом углу
- ✅ В консоли браузера (F12) нет ошибок 500

### 3.2. Создание доски
1. Нажмите "➕ Новая доска" (если кнопка есть)
2. Введите название: "Тестовая доска"
3. Нажмите "Создать"

**Ожидаемый результат:**
- ✅ Доска создана
- ✅ Появилась в списке досок
- ✅ Можно переключиться на эту доску

### 3.3. Создание списка
1. На доске нажмите "➕" для создания списка
2. Введите название: "В работе"
3. Нажмите "Создать"

**Ожидаемый результат:**
- ✅ Список появился на доске
- ✅ Можно добавлять карточки

### 3.4. Создание карточки
1. В списке нажмите "➕"
2. Заполните:
   - Название: "Тестовая задача"
   - Описание: "Описание задачи"
   - Приоритет: Высокий
   - Дедлайн: выберите дату
3. Нажмите "Добавить"

**Ожидаемый результат:**
- ✅ Карточка создана
- ✅ Видно название, описание, приоритет
- ✅ Карточку можно перетаскивать (drag & drop)

### 3.5. Управление пользователями
1. Нажмите кнопку "Пользователи" в верхнем меню
2. В модальном окне введите:

3. Нажмите "Создать пользователя"

**Ожидаемый результат:**
- ✅ Пользователь создан
- ✅ Появился в списке пользователей
- ✅ Можно назначить на карточку

### 3.6. Назначение пользователя на задачу
1. Откройте любую карточку (клик по ней)
2. В разделе "Исполнители" выберите пользователя
3. Нажмите "Назначить"

**Ожидаемый результат:**

- ✅ На карточке появился аватар пользователя
- ✅ Можно снять пользователя с задачи

## 8️⃣ Быстрая диагностика проблем

### Проблема: 500 ошибки в API

**Решение:**
```bash
# 1. Проверьте backend
curl http://localhost:3223/health

# 2. Проверьте логи backend (в терминале где запущен npm run dev)

# 3. Проверьте подключение к БД
docker compose exec postgres psql -U trello -d trello -c "SELECT 1;"

# 4. Проверьте таблицы
docker compose exec postgres psql -U trello -d trello -c "\dt"
```

### Проблема: Frontend не загружается

**Решение:**
```bash
# 1. Проверьте что frontend запущен
lsof -i :3000

# 2. Проверьте логи frontend (в терминале где запущен npm run dev)

# 3. Откройте консоль браузера (F12) и посмотрите ошибки
```

### Проблема: Данные не сохраняются

**Решение:**
```bash
# 1. Проверьте что backend получает запросы
# (должны быть логи в терминале backend)

# 2. Проверьте что данные попадают в БД
docker compose exec postgres psql -U trello -d trello -c "SELECT * FROM \"Board\";"

# 3. Проверьте консоль браузера на ошибки
```
